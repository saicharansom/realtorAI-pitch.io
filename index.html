The Solution

One platform. Two unfair advantages.

RealtorAI automates content creation and lead qualification end-to-end — from the moment photos are uploaded to the moment the lead says "let's write an offer."

🎬

Video Studio

Drag and drop up to 20 listing photos. Video Studio — Deep Dive

From photos to published reel in 4 steps

No editing software. No freelancers. No templates. Every video is generated fresh from the actual listing photos.

1

Upload photos

Drag and drop up to 20 listing images. Client-side canvas resizes and compresses to max 1920px JPEG before upload — keeping payloads small.

2

AI Script

Images are uploaded to Butterbase storage to get public HTTPS URLs. GLM-5 vision model reads the photos and writes a script: one hook line, 3 highlight beats, and a CTA.

3

Seedance Video

ByteDance's Seedance 2.0 model generates a 15-second cinematic 9:16 reel using the photos as first-frame and reference images. Polled every 10s, times out after 10 min.

4

Post-process + Export

ffmpeg burns timed text overlays (hook at 0s, beats at 3/7/10s, CTA at 13s) and mixes in an AI voiceover from IonRouter TTS. Final MP4 served from /media/.

Fallback chain if Seedance unavailable:
1 Cumulus/IonRouter native video model
2 ffmpeg photo slideshow with zoom-pan

📲 iMessage — Photon Spectrum SDK

The Spectrum SDK connects at server startup and streams every inbound iMessage to the handler. The agent replies in-thread via space.send(), showing a typing indicator while composing. An HTTP webhook at /api/webhook/imessage handles pushes when the SDK isn't streaming.

💻 Web Chat — Embeddable Widget

Buyers visit /chat?listing=UUID and get a mobile-style chat UI. Session identity is a UUID persisted in localStorage. Same agent, same CRM pipeline — realtors see web and iMessage leads in one unified inbox.

Tech Stack

Purpose-built on best-in-class APIs

Every service was chosen for a specific capability. One key per provider. No bloat, no overlap.

AI & Video Layer
🧠
IonRouter / GLM-5
OpenAI-compatible API powering text generation (scripts), photo vision (image analysis), lead qualification agent, and TTS voiceover — one key covers all four modalities.

✂️
ffmpeg
Post-processes Seedance output: timed drawtext captions, voiceover mixing. Also the final fallback for a zoom-pan photo slideshow when AI video is unavailable.

🗄

Live Demo

4-minute walkthrough

Every step below is live, not mocked. All AI calls hit real APIs.

1

Drop listing photos into Video Studio

Open the dashboard at localhost:8000 and drag 5–8 listing photos into the Video Studio panel. The client compresses each image to JPEG and shows a thumbnail grid. Set an optional custom prompt like "Beachfront condo with ocean views."

POST /api/listings/generate-from-images
2

Watch the AI script appear, then the video

Images upload to Butterbase storage. GLM-5 vision reads them and returns a script. Seedance begins rendering. The UI shows "Generating video with Seedance…" for ~30–60 seconds. The final MP4 auto-plays in the results panel below the script preview (hook, beats, CTA visible).

3

Send a test iMessage to the Photon number

Text the agent's Photon number: "Hi, is 123 Oak Ave still available?". Within seconds the agent replies warmly, asks if you're buying, renting, or selling. The lead card appears in the pipeline under New, then immediately moves to Qualifying.

Photon Spectrum SDK → handleInboundMessage → GLM-5 → space.send()
4

Watch the qualification happen in real time

Answer the agent's questions (budget, pre-approval, timeline). Open the Lead Drawer in the dashboard to see qualifying data populate field by field with each exchange. The lead status advances automatically as the agent gains confidence.

5

Book a showing — lead advances to Showing Scheduled

Reply "I'd love to see it Saturday at 2pm." The agent confirms, appends the calendar link, and the pipeline card moves to Showing Scheduled. The cron job will fire a 24h reminder and a 1h reminder automatically.

POST /api/showings → lead status → showing_scheduled
6

Offer stage → realtor notification

Mark the lead Offer Stage from the drawer. The header immediately shows a pulsing gold notification button: "Sarah C. is ready for you." The agent sends a graceful handoff message. The realtor takes over from here.
